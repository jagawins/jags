How to use it

  1. Click AI Mode and enter your API key for full AI features.
  2. Paste ebook text or upload a PDF / EPUB.
  3. Set the book type and your reading goal.
  4. Hit Generate plan — or Generate with AI.
  5. Use the chat to ask questions about the text.
  6. Study the flashcards for retention.

Input

Upload a PDF or EPUB to auto-fill the text field, or paste text manually.
Tip: For a long ebook, start with the table of contents and first chapter.
